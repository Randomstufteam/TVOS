# Install TVOS

Ask for the TV's model if you don't have it. Then fetch the prompt for this release and follow it exactly, on the real TV:

```bash
git clone --depth 1 --branch v1.0.0 https://github.com/Randomstufteam/TVOS.git
```

Read `TVOS/PROMPT.md` and work through its numbered steps from step 2, because the clone above is step 1. Read
`docs/base-procedure.md` before touching the TV. Its safety rules are not optional.
